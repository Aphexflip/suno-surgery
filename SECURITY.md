# Security policy

## Scope

Suno Surgery is an experimental local music editing workflow. It is not a hosted service. It does not need a Suno password or API token, and it does not automate Suno account actions.

Please do not add unofficial session handling, cookie collection, private Suno endpoints, or third party account access.

## Reporting an issue

If you find an issue that could expose user files, credentials, browser data, or execute unexpected code, **do not include secrets, private audio, account data, or exploit details in a public issue**.

Use GitHub's private security reporting feature if it is enabled for this repository. If it is not available, open a public issue containing only a general description and request a private contact method. Never paste sensitive details into the issue.

The project is independently maintained and does not promise a fixed response time or a bug bounty.

## Safe usage

Only process audio files you have permission to use. Keep your original copies. Inspect changes and generated output before relying on them. Browser and CLI components are experimental and have not been comprehensively audited.

## Supported versions

The latest default branch is the only version currently maintained. No published security support schedule is promised.
